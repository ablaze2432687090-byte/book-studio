# 使用指南

## 首次使用与发布预览版

新建画册、展厅或先整理素材均可，不需要 API。安装器选择的语言用于首次启动；已有语言设置不被升级覆盖。

设置 → 数据与备份 → 存储位置，可选择备份目录或迁移作品。程序先保存并备份，再复制、校验每个文件，成功后切换；旧仓库不删除。请保留可用磁盘空间，操作时不要断开外接磁盘。迁移后磁盘不可用时程序会停止启动并提示连接原磁盘，不会拿空仓库替代。已有备份不会随位置选择搬走。

导出时会显示保存、生成和打包阶段，不伪造百分比。客户端选择保存位置后会确认保存结果，可打开文件所在文件夹。取消保存后可重新点击下载，无需重新编辑作品。

设置 → 关于与更新，可主动检查官方版本并手动下载安装；不会自动执行安装包。未配置仓库、未发布、网络故障和请求受限会分别说明。诊断导出只含版本、系统、连接状态和数量，不含原始日志、路径、作品名称或密钥。不要公开原始日志或备份。

## 创建与整理

项目中心选择画册或展厅，二者属于同级项目且独立保存。图库是公共资源工具，支持分类、标签、归档、回收站。向展厅导入独立副本，图库整理不会破坏已经导入的作品。

画册支持手动导入成品页面、可选 AI 接口、复制指令给外部 AI。无需 API 也能完整编辑与导出。展厅添加作品后自动延长，编辑最小缩放为默认 100%；作品总览可查看整墙。

## 编辑与观看

书本支持鼠标拖动、左右箭头及键盘方向键翻页。图片构图支持平移、缩放与非破坏裁剪。材质、灯光和背景为可关闭屏幕效果，静态 PDF 不等于互动渲染。

工具栏与设置共用玻璃透明度，默认 45%，可调 0–80%。背景明暗只调整场景。小屏使用实色操作栏保证可读性。切换 English 只改变工具文字，不修改项目内容。

撤销/重做最多保留本次编辑 60 步；恢复点最多 30 个，不能替代完整备份。归档与移入回收站都不删除原图，回收站不会自动清空。

## 保存与交付

作品自动保存。退出前等待保存与导出完成；未保存失败时不会强行退出。可在设置中自选退出确认。PDF 用于静态阅读，离线 ZIP 保留互动效果，完整解压后打开入口 HTML。每次导出是独立快照，没有实时更新外发文件的功能。

## 数据与设置

设置 → 常规与显示可切换语言、密度、动效和缩放；数据与备份中可打开实际目录、备份、导入与恢复。默认 `%APPDATA%/BookStudio`。升级不覆盖作品，卸载默认保留数据。不要在程序运行时手动移动目录。

AI 设置可选。保存配置不生成图片；生成请求和服务商计费需自行确认。图片提交给所配置服务商后适用其数据政策；密钥不随备份、作品或客户包导出。

快捷键：Ctrl+, 设置；Ctrl+S 保存；Ctrl+Shift+H 项目中心；Ctrl+Z 撤销；Ctrl+Shift+Z 重做；Esc 关闭顶层弹窗；F11 全屏；Ctrl+0 恢复界面缩放。
